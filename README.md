# Meu Fluxo — Atualizações oficiais

Canal de distribuição do **Meu Fluxo**, aplicativo Android de controle financeiro.

Criado por **Denny Ximenes**.

## Baixar o aplicativo

Acesse a seção **Releases** deste repositório e baixe o APK da versão mais recente.

> Para atualizar, instale o novo APK por cima da versão anterior, mantendo os dados do aplicativo. Antes de instalar, faça um backup pelo próprio aplicativo. Não desinstale a versão antiga.

## Novidades da versão 1.0.6

- Corrigido o toque nos campos do formulário “Recuperar minha conta”.
- A tela de fundo fica bloqueada quando a janela de recuperação está aberta.
- Mantidos os recursos de segurança e backup criptografado adicionados na 1.0.5.

## Segurança

Os arquivos privados de assinatura, cadastros pessoais e senhas **não são publicados** neste repositório.

## Atualizações

O arquivo `update.json` é gerado automaticamente após a publicação de cada Release válida. Ele disponibiliza versão, URL do APK e SHA-256 para uso por versões futuras do app.

**Observação:** a versão 1.0.6 ainda não possui verificação automática de atualizações dentro do aplicativo. No momento, a instalação é feita manualmente pela página de Releases.
